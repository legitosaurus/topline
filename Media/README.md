# Status strip texture

Generated with the built-in image generation tool for Topline. This is original
generated artwork inspired by the dark leather and weathered bronze window frames
in the user's WoW screenshot, not an extracted Blizzard asset.

- `StatusStrip-source.png`: original generated 1536x1024 artwork.
- `StatusStrip.tga`: RGB, uncompressed, 256x32 runtime texture (~24 KiB).

The runtime image is only resized and converted for WoW compatibility. Topline
repeats it horizontally at its 8:1 aspect ratio; the source PNG is not loaded in game.

## Generation prompt

Use case: stylized-concept. Asset type: actual tileable raster texture for a thin World of Warcraft Classic / Forever status bar, not a screenshot or mockup. Generate one full-bleed 1536x1024 texture sheet: dark brown-black aged leather with subtle fine mottling and hand-painted old fantasy game UI material. Across the absolute top and absolute bottom edges, narrow continuous antiqued brass/bronze mouldings with worn gold highlights and dark recessed bevels, each occupying about 8 percent of image height. Center 84 percent is very dark restrained leather, quiet enough behind tiny white text. Horizontally seamless: left/right edges continue the same leather and straight metal rails; NO side borders, corners, ornaments, studs, symbols, text, characters, UI elements, logos or blank margins. Front-on orthographic flat material, no perspective. Match the warm weathered bronze and dark leather of original WoW character-window title bars, not sleek modern gold lines. Texture will be reduced to a small horizontal repeating strip, so make grain subtle, rail profiles readable, highlights muted. Entire canvas is the texture.
