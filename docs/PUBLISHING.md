# Topline listing materials

## Suggested short description

A lightweight top bar for WoW: Forever with XP, money, bags, durability, travel,
performance, mail, and time. Hover for details; right-click to customize.

## Project description

Use the player-facing sections of the root README as the listing description.
Omit the final developer-reference link when copying to a listing site unless
replacing it with a real public repository URL. No project, download, support,
or issue-tracker URL has been invented in these materials.

The README image uses a repository-relative path. Upload the original image
from `screenshots/topline-overview.png` to the listing's image gallery/editor
and insert the hosted image there; do not paste a local Windows path.

## Screenshot selection

The supplied Stormwind image is an unedited overview crop. It shows the entire
bar, mail, both groups, and enough of the default UI to establish placement.
Its very wide, shallow composition works well as a supporting strip overview,
but the text becomes small in thumbnails or narrow page layouts.

For a stronger lead image, capture a closer view at a readable UI scale with:

- A real, populated XP/hour value after earning XP for at least a minute.
- The XP tooltip open, showing the depth behind the simple strip.
- Enough gameplay and default UI to show the addon in context, without a large
  empty scene distracting from the information bar.

Keep the overview as a second image. A third image showing the customization
or overflow menu would explain the controls. Use real gameplay captures; do not
paint in artificial statistics. XP showing N/A in the supplied shot is normal
before sufficient session data, but a populated example is clearer to new users.

Before uploading screenshots, review visible player/guild names and decide
whether you want them in a public listing. The supplied image has not been edited.

## Scope and release notes

Describe support as Forever / `_classic_beta_`, Interface 16001, until other
clients have actually been validated. Preserve the README's short beta storage
note. This documentation update does not publish a project, select a license,
or certify compatibility with other WoW branches.
