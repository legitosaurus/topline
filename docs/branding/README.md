# Topline listing logo

`topline-logo.png` is a square logo generated with the built-in image-generation
tool. It is intended for the addon listing and is not loaded by the game.
The generated PNG is preserved without edits. The design uses a bronze T and
Topline wordmark over dark leather to match the addon's visual theme.

## Generation prompt

Use case: logo-brand. Asset type: square addon listing logo for Topline, a lightweight top-of-screen information bar for World of Warcraft: Forever. Generate one finished 1024x1024 PNG, exactly 1:1. Original fantasy interface identity: a bold sculpted bronze capital T emblem whose broad upper horizontal stroke evokes a thin status strip, above the exact word "TOPLINE" in highly legible custom fantasy serif lettering. Centered compact composition, generous safe margins, strong silhouette readable at small icon size. Dark charcoal brown leather background, restrained aged bronze and warm gold bevels, subtle crafted texture, understated classic fantasy UI finish matching dark leather and bronze addon trim. Keep design simple and premium, crisp edges, balanced lighting, high contrast. No extra words, no tagline, no characters, no weapons, no Warcraft or Blizzard logos, no copied faction symbols, no mockup, no watermark, no outer whitespace. Opaque square background.
